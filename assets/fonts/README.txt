Place a monospace font file here (WOFF2 recommended) named `SFMonoLocal.woff2` to enable pixel-exact rendering.

Steps:
1. Download a monospace font you own or use (e.g., SF Mono, Fira Mono, IBM Plex Mono) and convert to WOFF2 if needed.
2. Put the font file at: `assets/fonts/SFMonoLocal.woff2`.
3. Reload the page — the site will use the local font for the terminal when available.

Note: I cannot bundle licensed font binaries here. Place your chosen font file in this folder to use it.
